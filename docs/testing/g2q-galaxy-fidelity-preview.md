# G2Q experimental unsigned preview

Windows x64 requires WebView2 Runtime. Linux x64 requires GTK 4 and WebKitGTK 6 runtime libraries. Extract the archive, verify both README and executable against SHA256SUMS, then run eridion.exe (Windows) or chmod +x eridion && ./eridion (Linux). This is an experimental unsigned build, not an installer or release. Preserve your normal profile backup.

Atlas detail downloads remain off until explicitly enabled by the owner. Requested/Displayed diagnostics distinguish genuine detail from verified fallback. Close-zoom symbols represent occupied density bins, not individual stars. Colors remain the published density palette.

Acceptance: open Galaxy Map; Fit Galaxy then Fit Route; zoom and pan all three aligned projections; compare Requested/Displayed and pending counts; explicitly enable detail downloads if desired; confirm fallback refines to L7; toggle Show Route while retaining destination/current markers; resize and test a paired laptop; restart offline with cached tiles. Viewers cannot manage downloads or permissions. No game commands or upload permissions are added.

Renderer reference: Jakoczig/Eridion-Galaxy-Painter atlas.py at 0acb1a6350cc4ade5d211de3b336194151be3e63 (GPL-3.0). Browser Canvas adapts its bounded occupied-bin rendering; ERIDION retains its existing license and signed Atlas verification.
